# Notes Module for Bitrix D7

Модуль для управления заметками через RESTful API с веб-интерфейсом на Vue.js.

## Возможности

- ✅ Создание заметок
- ✅ Просмотр списка всех заметок
- ✅ Просмотр отдельной заметки по ID
- ✅ Редактирование заметок
- ✅ Удаление заметок
- ✅ Валидация данных через ActionFilter
- ✅ Автозагрузка классов (Autowiring)
- ✅ Веб-интерфейс на Vue.js 3

## Установка

### 1. Скопировать модуль

Скопируйте папку `local/notes` в директорию `local/` вашего Битрикс проекта.

### 2. Установить через админку

1. Перейдите в админ-панель: `Настройки` -> `Модули`
2. Найдите модуль "Notes - Сервис заметок"
3. Нажмите кнопку "Установить"

### 3. Проверить установку

После установки будет создана таблица `b_notes` в базе данных.

## API Эндпоинты

### Получить все заметки
```
POST /local/notes/api/list/
Content-Type: application/x-www-form-urlencoded

action=list
```

**Ответ:**
```json
{
  "success": true,
  "data": [
    {
      "ID": 1,
      "TITLE": "Моя заметка",
      "CONTENT": "Содержание заметки",
      "AUTHOR_ID": 1,
      "CREATED_AT": "2025-01-31 12:00:00",
      "UPDATED_AT": "2025-01-31 12:00:00"
    }
  ]
}
```

### Получить заметку по ID
```
POST /local/notes/api/get/?id=1
Content-Type: application/x-www-form-urlencoded

action=get
```

**Ответ:**
```json
{
  "success": true,
  "data": {
    "ID": 1,
    "TITLE": "Моя заметка",
    "CONTENT": "Содержание заметки",
    "AUTHOR_ID": 1,
    "CREATED_AT": "2025-01-31 12:00:00",
    "UPDATED_AT": "2025-01-31 12:00:00"
  }
}
```

### Создать заметку
```
POST /local/notes/api/create/
Content-Type: application/x-www-form-urlencoded

action=create&title=Заголовок&content=Содержание&author_id=1
```

**Ответ:**
```json
{
  "success": true,
  "data": {
    "ID": 1,
    "TITLE": "Заголовок",
    "CONTENT": "Содержание",
    "AUTHOR_ID": 1,
    "CREATED_AT": "2025-01-31 12:00:00",
    "UPDATED_AT": "2025-01-31 12:00:00"
  },
  "message": "Заметка успешно создана"
}
```

### Обновить заметку
```
POST /local/notes/api/update/
Content-Type: application/x-www-form-urlencoded

action=update&id=1&title=Новый заголовок&content=Новое содержание
```

**Ответ:**
```json
{
  "success": true,
  "data": {
    "ID": 1,
    "TITLE": "Новый заголовок",
    "CONTENT": "Новое содержание",
    "AUTHOR_ID": 1,
    "CREATED_AT": "2025-01-31 12:00:00",
    "UPDATED_AT": "2025-01-31 12:05:00"
  },
  "message": "Заметка успешно обновлена"
}
```

### Удалить заметку
```
POST /local/notes/api/delete/?id=1
Content-Type: application/x-www-form-urlencoded

action=delete
```

**Ответ:**
```json
{
  "success": true,
  "message": "Заметка успешно удалена"
}
```

## Валидация

Модуль использует ActionFilter для валидации данных:

### Правила валидации для создания:
- `title` — обязательно, до 255 символов
- `content` — обязательно
- `author_id` — обязательно, положительное число

### Правила валидации для обновления:
- `id` — обязательно, положительное число
- `title` — при указании не должен быть пустым, до 255 символов
- `content` — при указании не должен быть пустым

### Ошибки валидации возвращаются в формате:
```json
{
  "success": false,
  "errors": [
    "Поле 'title' обязательно для заполнения",
    "Длина заголовка не должна превышать 255 символов"
  ]
}
```

## База данных

### Таблица `b_notes`

| Поле | Тип | Описание |
|------|-----|----------|
| ID | INT | Первичный ключ, автоинкремент |
| TITLE | VARCHAR(255) | Заголовок заметки |
| CONTENT | TEXT | Содержание заметки |
| AUTHOR_ID | INT | ID автора |
| CREATED_AT | DATETIME | Дата создания |
| UPDATED_AT | DATETIME | Дата обновления |

### Индексы
- Первичный ключ: `ID`
- Индекс: `IDX_AUTHOR_ID` на поле `AUTHOR_ID`

## Удаление

1. Перейдите в админ-панель: `Настройки` -> `Модули`
2. Найдите модуль "Notes - Сервис заметок"
3. Нажмите кнопку "Удалить"
4. Подтвердите удаление
