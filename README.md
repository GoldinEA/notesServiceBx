# Инструкция по развертыванию сервиса заметок

## Требования
- BitrixDock окружение
- Bitrix24 или стандартный Bitrix

## Установка

### Шаг 1: Развертывание BitrixDock
Разверните окружение BitrixDock — файл конфигурации `.env` уже подготовлен и находится в проекте.

```bash
docker compose -p bitrixdock --profile workspace up -d
```

### Шаг 2: Установка Bitrix
Выберите один из вариантов:

**Вариант А: Новая установка**
- Перейдите по адресу установки Bitrix
- Следуйте стандартному мастеру установки

**Вариант Б: Перенос существующего проекта**
- Перенесите файлы проекта в директорию BitrixDock
- Импортируйте дамп базы данных
- Обновите настройки подключения к БД в `/bitrix/.settings.php`

### Шаг 3: Установка модуля
- Войдите в административную панель Bitrix
- Перейдите в раздел **Marketplace** → **Установленные решения**
- Найдите модуль сервиса заметок
- Нажмите **Установить**


После успешной установки будут доступны:

- **Swagger документация**: `/local/swagger/`
- **Страница с заметками**: `/notes/`

## Тестирование

Функционал протестирован в среде Bitrix24.
